Google Tasks MCP Server

An open-source MCP server that gives Claude, Codex, Cursor, and other AI clients full read/write access to your Google Tasks: create, update, complete, move, and delete tasks and task lists, with real due dates and subtasks.

npx -y @girmmy/google-tasks-mcp-server

It runs locally on your computer and talks directly to Google using an OAuth client you create yourself. Nothing passes through a server operated by anyone else.
